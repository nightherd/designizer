import "github.com/switchyard/switchyard-go"

client, _ := switchyard.New(switchyard.Config{
	URL: "https://flags.acme.internal",
	Key: os.Getenv("SWITCHYARD_KEY"),
})

func Checkout(u User) Result {
	ctx := switchyard.Context{UserID: u.ID, Attrs: u.Attrs()}
	// evaluated locally — no network round-trip
	if client.IsEnabled("new-checkout-flow", ctx) {
		return onePageCheckout(u)
	}
	return legacyCheckout(u)
}

// architecture

If Switchyard goes down, your app doesn't notice.

SDKs keep a full copy of the ruleset in memory and fall back to a local snapshot. The server is the control plane, never the critical path.

Streaming, not polling

Changes propagate over server-sent events. Median global propagation is 41ms.

Fail static

If the stream drops, SDKs keep serving the last known ruleset and reconnect with backoff.

Privacy by default

User context never leaves your process. The server only sees which flags exist, not who saw them.
